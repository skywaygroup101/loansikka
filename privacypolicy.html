2. What the Application Collects

The Application collects the following categories of information. Fields marked Optional are shared only if you choose to provide them.

Personal and Financial Profile Required

Provided by you directly, so that the Service Provider can build your credit assessment profile.

  • Education level
  • Work type and years of working experience
  • Industry and designation / occupation level
  • Monthly income range
  • Residence / address property type
  • Marital status, number of children, religion

Identity Verification Required

Collected to verify that you are who you say you are.

  • A photograph of your PAN card, taken with the camera or selected from your gallery
  • The image is compressed on your device before it is uploaded
  • Your full name and PAN number, as entered by you

Emergency Contacts Required

Up to two emergency contacts, used for identity and security purposes.

  • Relationship, name and mobile number of each contact
  • You may type these in manually, or pick them through your device's system contact picker
  • The Application does not request access to your full contact list. Only the single contact you pick is read, through the temporary permission granted by the system picker

Financial SMS Optional

Shared only if you grant SMS permission. If you decline, the Application continues normally and simply submits an empty list.

  • Messages are filtered on your device first, and only messages with financial, transactional or billing content are selected
  • For each selected message: sender address, message body, timestamp, message type, sent date and delivery status flags
  • Personal and non-financial messages are never selected or uploaded

Device and Technical Data Required

Collected automatically for fraud prevention, risk control and service stability.

  • Device model, brand, device name, Android version and API level
  • Physical screen size (in inches)
  • Total and available memory, and internal / external storage capacity
  • Device identifiers: Android ID, Google Advertising ID (GAID), Adjust ID and Adjust attribution data, and the app instance identifier
  • System language and locale
  • Mobile network operator name and connection type (2G / 3G / 4G / 5G / Wi-Fi)
  • Wi-Fi IP address
  • Battery level and charging state
  • Application version name, version code and package name

Installed Applications Required

The Application reads the list of applications installed on your device for anti-fraud assessment.

  • Application label and package name
  • First install time and last update time
  • Version name and version code
  • Whether the application is a system application

Approximate Location Required

Approximate (coarse) location used for risk control and regional compliance. The Application requests only ACCESS_COARSE_LOCATION — it does not request precise GPS location.

  • Approximate latitude and longitude

What the Application does not collect: the Application does not read the contents of your contact list, does not read non-financial SMS, and does not access precise GPS location.
